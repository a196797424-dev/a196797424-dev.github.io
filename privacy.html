隐私政策 / Privacy Policy

Wuthering YouTube Analytics

生效与最后更新日期：2026-10-19
维护者：a196797424-dev · 联系邮箱：a196797424@gmail.com

1. 适用范围

本政策适用于 Wuthering YouTube Analytics 本地只读工具及其说明网站。工具供维护者本人及获授权的频道管理者分析其有权访问的频道，不面向公众提供账号注册服务。

2. 读取哪些数据

经 Google OAuth 授权，工具通过 YouTube Data API 和 YouTube Analytics API 读取频道标识、名称、handle、频道统计、上传列表、视频标题、说明、发布时间、时长、可见性及视频统计；其中可能包括账号有权读取的非公开视频信息。分析报表包括观看次数、观看时长、平均观看时长或比例、订阅增加和减少等非收益指标。

工具在本地保存 OAuth 访问凭据和刷新凭据，以便在授权有效期间继续读取数据。工具不接收 Google 密码，也不申请邮件、通讯录、云端硬盘或视频写入权限。

3. 数据用途

数据用于识别正确频道、获取表现快照、比较内容表现以及按管理者要求生成报告和建议。工具不会将这些数据用于广告定向、信用评估或出售。

本工具使用及向其他应用传输通过 Google API 获得的信息，将遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

4. 本地存储与安全

客户端配置与 OAuth 凭据使用 Windows 当前用户的 DPAPI 加密，保存在管理者电脑上的应用私有目录。频道身份绑定、数据快照与研究报告保存在本地工作目录；这些报告文件本身未单独加密，其访问受电脑账号、目录权限及管理者的备份设置影响。

公开网站与公开代码仓库不包含 OAuth 凭据、客户端密钥、后台报表或频道私密数据。凭据不应被粘贴到聊天、上传到公开仓库或写进报告。

5. AI 辅助分析及第三方处理

管理者使用 OpenAI Codex 请求分析时，完成该任务所需的频道资料、指标和报告片段可能随工具结果或聊天内容发送至 OpenAI。此流程并非全部在本地离线完成。发送的内容不应包含 OAuth 密钥或访问凭据。

这些内容用于管理者请求的分析功能，其在 OpenAI 服务中的处理、保留和数据控制取决于所使用产品的条款、账户设置与 OpenAI 隐私政策。本工具不提供将频道数据汇集为通用模型训练数据集的功能。若不希望数据进入该服务，可仅在本地运行和查看报表，不将结果交给 Codex。

Google 处理账号登录、授权及 API 请求，适用 Google 隐私政策。本说明网站由 GitHub Pages 托管，托管方可能处理 IP 地址等访问日志，详见 GitHub 隐私声明。本网站没有自行添加广告、访问分析脚本、表单或 Cookie。

6. 保留、撤销与删除

本地快照与报告目前由管理者手动管理，不设自动删除任务；仅应在完成获授权分析及相关记录所需期间保留，并遵守适用的 YouTube API 数据保留要求。过期快照不得当作当前数据使用。凭据可保留至管理者删除、授权撤销或 Google 判定失效。

你可随时在 Google 账号的第三方连接管理页找到本应用并撤销授权。撤销会阻止后续依赖该授权的读取，但不会自动删除此前已下载的本地文件或聊天记录。

若需删除本地数据，可向工具维护者发出删除请求，或在自己的电脑上删除本应用保存的凭据、频道绑定、快照、报告及相关备份。对已进入 Codex 的内容，请同时使用相应产品的聊天删除与数据控制功能；本地删除不会代替云端删除。

删除、访问或更正请求请联系 a196797424@gmail.com，说明相关频道与请求范围。请勿通过邮件发送密码、OAuth 凭据或密钥。

7. 政策更新

如工具的数据范围、用途或处理方式发生变化，维护者将在本页更新说明与日期；需要新增 Google 权限时，须重新通过相应授权流程。
