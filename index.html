频道管理者的只读分析工具

Wuthering YouTube Analytics

在频道管理者授权后，通过 YouTube 官方 API 获取频道与视频表现，用于查看数据、比较内容表现和制作分析报告。

隐私政策 / Privacy Policy联系维护者

这个工具做什么

这是由 GitHub 用户 a196797424-dev 维护、供本人及获授权频道管理者使用的本地桌面工具。工具读取频道身份、视频资料、观看次数、观看时长、平均观看比例和订阅变化，辅助频道管理者理解内容表现。分析报告可由 OpenAI Codex 协助生成。

此网站提供应用说明与隐私政策。实际数据读取在管理者的电脑上运行，网站没有登录入口，也不展示频道后台数据。

为什么需要 Google 授权

  • youtube.readonly：识别授权频道，并读取频道及视频信息，包括账号有权访问的非公开视频资料。
  • yt-analytics.readonly：读取授权频道的非收益分析报表，用于表现分析。

授权由 Google 的登录与同意页面完成。工具不会索取 Google 密码；当前权限不允许上传、编辑或删除视频，也不允许发表评论。

数据由谁使用

数据用于授权管理者提出的频道分析任务。本地程序保存凭据与报表；使用 Codex 协助分析时，任务所需的频道数据可能发送至 OpenAI 处理。具体存储、共享、撤销与删除方式见隐私政策。

本工具由个人独立维护，不代表 Google 或 YouTube，也未声称获得其认证或背书。
